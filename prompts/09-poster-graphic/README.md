## Tips for Poster & Graphic Design

- **Always specify aspect ratio**: 2:3 for movie posters, 1:1 for social media, 16:9 for banners
- **Typography control**: Name the font style ("sans-serif", "serif", "Art Deco") and position
- **Credit blocks**: "credits block at bottom" adds professional poster realism
- **Art style era**: "1930s Art Deco", "psychedelic 60s", "Swiss design" -- era references are powerful
- **Color palette**: Name 3-4 specific colors to avoid generic palettes
- **For infographics**: Use `quality="high"` for dense labels and diagrams
- **For comics**: Define narrative as clear visual beats, one per panel, with concrete action descriptions
