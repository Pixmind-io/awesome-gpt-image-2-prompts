## 为什么需要这个仓库？

GPT Image 2 支持 **20,000 字符** 的提示词——远超竞品——但大多数用户只用了冰山一角。本仓库收集了摄影师、设计师、游戏美术和 AI 研究者经过实战验证的提示词。

你将获得：
- **100+ 可直接复制使用的提示词**，覆盖 10 个类别
- **8 槽位结构化提示词公式**，适用于复杂场景
- **常见失败案例与修复方法**，来自真实生产经验
- **中英双语** 文档

## 快速开始

1. 浏览下方的 [提示词分类](#提示词分类)
2. 复制符合你需求的提示词
3. 粘贴到 ChatGPT 或 OpenAI API 中
4. 每次只调整一个要素（灯光、镜头角度、风格）来迭代

> **专业提示：** 如果生成结果 80% 符合预期，不要重写整个提示词。复制它，只改一个元素，然后重新生成。达到精品级画面的平均迭代次数：~2.8 次。

## 提示词工程指南

### 8 槽位结构化公式

适用于复杂场景，借鉴自电影制作流程：

```
# 场景 SCENE
[设定：地点、时间、天气、历史时期]

# 角色 CHARACTERS
- 角色A：[外貌描写、服装、姿势、表情]
- 背景群演：[简要描述]

# 构图 COMPOSITION
[取景：全景/中景/特写。镜头角度。焦距。景深。]

# 灯光 LIGHTING
[光源、方向、硬度、色温、阴影行为]

# 色彩 COLOR
[3-4个颜色词描述调色板。调色方向。]

# 风格 STYLE
[一个主要参考。例如："Roger Deakins 摄影风格"]

# 技术 TECHNICAL
[分辨率、胶片颗粒、纵横比、质量标记]

# 排除 EXCLUSIONS
[要避免什么："无文字、无Logo、无水印"]
```

### 核心原则

1. **灯光 > 镜头 > 主体** — 灯光方向和镜头选择精确，主体模糊也能出好片。反之不行。

2. **具体名词胜过形容词** — "一位28岁红棕色头发的女性穿驼色风衣在雨中穿过曼哈顿十字路口" >> "一个美女在城市里"

3. **说风格，不说艺术家** — "Ufotable 制作品质" 或 "70年代意大利恐怖片风格" 比直接用在世艺术家名字更安全

4. **一个主导风格锚点** — 超过约 1,200 词后，形容词开始相互稀释。选定一个锚点风格

5. **复杂场景先写环境** — "在一间烛光摇曳的17世纪英式图书馆中..." 先建立场景框架

### 常见问题与修复

| 问题 | 修复方法 |
|------|---------|
| 画面平庸无生气 | 使用具体名词和具体地名 |
| 手指数量错误 | 让手握住物品，或裁剪到肩膀以上 |
| 图中文字乱码 | 保持文字极短，或加入 "no text, no letters" |
| 灯光方向被忽略 | 具体命名方向、硬度和阴影覆盖范围 |
| 场景错误 | 将场景描述移到提示词最前面 |
| 提示词过于拥挤 | 保持一个主导风格锚点，限制在 ~1,200 词 |
